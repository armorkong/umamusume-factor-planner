# ウマ娘血統プランナー

ウマ娘プリティーダービーの「継承（因子）」の組み方を、血統表の形で考えるためのツールです。
「親・祖父母・曽祖父母に誰を置き、どの赤因子・遺伝子・白因子を用意するか」を画面上で組み立て、受け継ぐ因子の★合計や育成開始時の適性を自動で計算します。

\---

## 1\. 開き方

ブラウザで [https://armorkong.github.io/umamusume-factor-planner/](https://armorkong.github.io/umamusume-factor-planner/) を開く

* データはその端末・そのブラウザの中だけに保存されます。他端末で同じ計画を使いたい場合は、「6. データの保存とバックアップ」の手順でJSONを書き出して、もう一方で読み込んでください。

\---

## 2\. 画面の構成

* **上部**：計画の切り替え／新しい計画／計画の設定（名前変更・複製・削除）／保有キャラ／PDFで書き出す／書き出し・読み込み／保存状態の表示
* **左（スマホでは上）**：血統表（系統樹）。左端が育成ウマ娘で、右へ親・祖父母・曽祖父母・4代前…と広がります
* **右（スマホでは下）**：「編集」タブと「受け継ぐ因子」タブ

スマホなど画面の狭い端末では、血統表が縦に並ぶ表示に切り替わります。各カードの「▾ 継承元」で先の祖先をたたんだり広げたりできます。

\---

## 3\. 基本の使い方

1. 「＋ 新しい計画」で、曽祖父母までの空の枠を作ります。
2. カードをクリックし、右の「編集」タブで入力します。

   * **キャラ**：名前・呼び名・衣装名・固有スキル名の一部を入力すると候補が出ます（例：「ステイゴールド」「嫁カフェ」「水着」）。選ぶと基本適性と固有スキル名が自動で入ります。
   * **状態**：自前／レンタル／予定。選んでいるボタンをもう一度押すと解除されます。
   * **メモ**：自由記入。
   * **青因子・赤因子・緑因子**：種類と★を選びます。
   * **遺伝子因子**：「＋ 遺伝子を追加」から。
   * **白因子**：検索欄に因子名を入力し候補から選びます。「まとめて入力する」を開くと「阿吽の呼吸3, 食い下がり2」の形式でまとめて追加できます。
   * **このキャラで狙う白因子**（状態が「予定」のときだけ）：育成で取得を狙う白因子を登録します。系統樹に「狙」と表示されます。
3. 赤因子は、血統表のカード上のドロップダウンからも直接選べます。キャラ名が未入力の「未設定」の枠でも選べます。
4. 「受け継ぐ因子」タブで、選んでいるカードが親2人・祖父母4人から受け継ぐ因子の★合計を確認します。

### 枠の操作（編集タブの「操作」）

* **＋ 親を追加**：親が2人未満のとき、枠を追加します（4代前以降も可）。
* **保有キャラに登録／保有キャラから配置**：よく使う因子キャラを、継承元2代分ごと登録・コピーできます。
* **因子を空にする**：キャラ情報だけを消します（継承元は残ります）。
* **この枠と祖先を消す**：中身を消しますが、枠の位置は残ります（下の枠が詰まりません）。
* **この枠を取り除く**：4代前以降の枠だけに表示され、枠そのものを系統樹から外します。

\---

## 4\. 自動計算のルール

### 育成開始時の適性

* 対象：そのキャラの親2人＋祖父母4人が持つ、同じ種類の赤因子の★合計
* ★合計が **1・4・7・10** に達するごとに、基本適性が1段階上がります（最大4段階、Aまで）
* 例：ステイゴールド（ダートG・マイルG）の継承元にマイル★7・ダート★3 → 開始時ダートF・マイルD

### 赤因子の選択制限

* 赤因子のドロップダウンには、**育成開始時の適性がA以上**の適性だけが出ます。
* 基本適性がわからないカード（衣装未選択で手動登録もない）は制限しません。
* 祖先を変えて条件を満たさなくなった赤因子は、消さずに「（B・付きません）」のように表示し、カードの欄が赤い斜線になります。

### 遺伝子が付く可能性

* 親2人＋祖父母4人の同じ種類の赤因子★合計が **6〜11で「可能性」、12以上で「確定」** と表示します。

### 受け継ぐ因子（集計）

* 選んでいるカードの親2人・祖父母4人のうち、入力済みの分を集計します（何も選んでいないときは育成ウマ娘）。
* 獲得している因子だけを表示します（赤因子・遺伝子・青因子・緑因子・白因子の別枠）。

\---

## 5\. 書き出し

|ボタン|内容|
|-|-|
|PDFで書き出す（上部）|表示中の計画の血統表を、枠付きでA4用紙1枚に出力します。縦長なら縦、横長なら横向きになります。ファイル名は計画名です|
|Excelで書き出す（受け継ぐ因子タブ）|選んでいるカードの集計を `計画名\_キャラ名\_受け継ぐ因子.xlsx` で保存します。シート「受け継ぐ因子」（計★は式なので編集すると再計算されます）と「継承元の一覧」の2枚です|
|書き出し・読み込み（上部）|全データをJSONファイルで保存・復元します|

* ブラウザの印刷画面を使います。
* Excelの作成にはネット接続が必要です。

\---

## 6\. データの保存とバックアップ

* 入力内容は自動で保存されます。右上の表示で保存先を確認できます。
* 「このブラウザに保存」：そのブラウザの中に保存Web版・HTMLファイル版のデータは、次の場合に消えたり見えなくなったりします。
* iPhoneのSafariでは、Webサイトのデータが長期間使われないと自動で削除されることがあります。大事な計画は定期的にJSONで書き出しておいてください。

\---

### 書き出し・読み込みの手順

**書き出す**

1. 「書き出し・読み込み」→「JSONファイルに書き出す」
2. ダウンロードフォルダに保存されます。
3. 保存できないときは「テキストで表示」で中身を表示・コピーできます。

**読み込む**

1. 移したい先のページで「書き出し・読み込み」を開く
2. 「ファイルを選択」でJSONを選ぶ（またはテキストを貼り付ける）
3. 「読み込んで現在のデータを置き換える」→「置き換える」
